# Use Environment

Users will use this application in various environments but wants to achieve their goals as fast as it is possible. Actions should have instant feedback and intuitive because users will not read instructions.

## Physical environment

- Smartphone (mostly), tablet, laptop
- Use in motion (pub, home, work, public transport)
- potential noise, distractions

## Technical environment
- Various network conditions (in motion)
- Various web browsers
- Various screen sizes (mobile phones -> desktops)
