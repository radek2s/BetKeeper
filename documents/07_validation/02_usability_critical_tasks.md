# Critical tasks
Actions where user error causes serious consequences. (invalid results, data loss, frustration)

## BKCT-1 - Bet creation

Risk: User assume that bet has been saved but something goes wrong and data are lost.

## BKCT-2 - Bet resolving

Risk: User resolve bet that claims have not yet been met and can't back to previous step.

## BKCT-3 - Bet completing

Risk: User marks that bet has been completed even if he didn't realized his stake.


## BKCT-4 - Accepting bet request

Risk: User is not aware of new pending bet request because is not notified about pending invitation.
